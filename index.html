📖 What just happened?

Every object you dragged into the bucket is like a variable in Python. A variable is a named container that stores a value so the program can remember it and use it again later.

Why do programmers use variables?

  • Store data — keep a value around so you don't have to re-type it.
  • Name things — a good name (score, username) tells you what the value means.
  • Change values — you can put a new value into the same bucket without breaking the program.
  • Make code modular & reusable — write once, change once, use everywhere.

Python syntax

score = 10      # put the value 10 into the bucket "score"
score = 20      # put a new value in the SAME bucket (the old one is gone)
print(score)    # → 20

A variable has three parts

PartExampleWhat it is
Bucket namescoreThe variable's name — what you call it
= (assignment)=The action of putting a value IN the bucket
Value10The data being stored

Rules to remember

  1. The bucket name must start with a letter or underscore — no digits, no spaces, no -.
  2. Names are case-sensitive: Score and score are two different buckets.
  3. You can overwrite a bucket — the old value is discarded when you assign a new one.
  4. One bucket, one value at a time. You can't shove two things into the same bucket.

Try it mentally

a = 5
b = a        # b now also holds 5
a = 9        # a now holds 9 — b is STILL 5
print(a, b)  # → 9 5

📖 Level 2 — Good Names & Data Types

You just sorted 20 items into labeled buckets. That’s exactly how a good programmer uses variables: each bucket had a name (the label) that described what goes inside.

1 · Meaningful naming

A variable’s name should tell you what it holds — without you having to look at the value.

# ❌ bad — what is "x" or "b"?
x = 10
b = ["apple", "juice"]

# ✅ good — the name describes the contents
score = 10
snacks = ["apple", "juice"]

In Level 2, food is a great name for a bucket of 🍎🍕🧃🍞. A bucket named stuff would be useless — you’d have to open it to see what’s inside.
